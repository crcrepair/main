4. Keyword research and where each term is used

Sources: Search Console via Windsor.ai (12 months: queries landing on /collection-booking/ and /come-to-you/, plus any query containing collect / pick up / courier / deliver / door / mail-in / post) and the SE Ranking UK keyword database.

So the page is written to own the exact service phrase ("collection and drop-off repair service", "collect … repair … return", "£29.95") and to pick up the doorstep / pick-up / mail-in long tail with natural wording, while sending the genuinely searched "doorstep" intent to /come-to-you/ rather than competing with it. Local signals: the five store names appear in the small print, the FAQ, the CTA and the schema areaServed.

Side finding: /come-to-you/ collects 3,455 impressions for "pocket geek help" and 831 for "pocket geek site" — Assurant's Pocket Geek app users, not repair customers. A one-line note on that page pointing them to Assurant would stop the mismatched traffic dragging it down.
